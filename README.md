# DiscoDungeon

Кооперативный рогалик в браузере на 1–4 игрока. Вместо кубиков диски, как в аэрохоккее: герои стоят фигурками на рунах у края комнаты и запускают диски в мобов, рудные жилы и кристаллы.

## Запуск

```bash
npm install
npm run dev      # локальный сервер с горячей перезагрузкой
npm test         # тесты генератора, камеры и карты забега
npm run build    # сборка в dist/
```

Игра публикуется на GitHub Pages автоматически при каждом пуше в `main` (workflow `.github/workflows/pages.yml`). В настройках репозитория нужно один раз выбрать Settings → Pages → Source: **GitHub Actions**.

## Сетевая игра

Главное меню → «Сетевая игра». Один игрок создаёт комнату и отправляет друзьям пятибуквенный код или ссылку, остальные входят по коду. Каждый выбирает своего героя (до трёх игроков), хозяин нажимает «Начать». Бой начинается, когда все нажали «Готов».

Браузер хозяина считает игру, остальные отправляют ему свои броски и получают состояние комнаты. Браузеры соединяются напрямую через WebRTC ([Trystero](https://github.com/dmotz/trystero)). Знакомят их публичные серверы сразу трёх сетей: Nostr, MQTT и трекеры BitTorrent, так что если одна сеть недоступна или заблокирована, хватит другой. Своего сервера не нужно. Если игрок вылетел, его героя пока ведёт хозяин, а игрок возвращается сам: при обрыве связи игра переподключается, после перезагрузки страницы (в течение 30 минут) сразу садится за своего героя. Браузер хозяина раз в секунду запоминает игру, поэтому после его вылета комната открывается заново с тем же кодом и с того же места, и остальные подключаются сами. Если прямое соединение не устанавливается из-за настроек сети (например, у мобильного оператора), трафик идёт через бесплатный публичный TURN-ретранслятор Open Relay.

Для локальной проверки можно поднять свой ретранслятор (`createWsRelayServer` из `@trystero-p2p/ws-relay/server`) и открыть игру с `?relay=ws://127.0.0.1:9001`.

## Управление

- Расстановка: герои сами встают на руны у ближних стен. Перетащи фигурку на другую руну (на занятой герои меняются местами), потом «В бой!» (в сетевой игре «Готов»). Пока герой не бросил, его можно переставить и в бою: выбери героя и тапни руну.
- Диски: на старте один диск за ход, второй и третий покупаются за руду в прокачке.
- Руда и искры общие на весь отряд. Справа список мобов: число в красном щитке значит удар, стрелка значит моб идёт, точка показывает цвет героя-цели.
- Тянуть фигурку назад и отпустить: бросок диска.
- Перетаскивание пустого пола: двигать комнату. Колесо или щипок: зум.
- Поворот: двумя пальцами, правой кнопкой мыши, Shift+колесо, клавиши Q и E. Кнопка ⌂ или 0 возвращает вид.

## Картинки фигурок

Фигурки рисуются кодом, пока нет картинок. Чтобы подключить картинку:

1. Положить PNG с прозрачным фоном в `public/assets/heroes/` или `public/assets/mobs/` (фигурка в полный рост, без подставки, ступни у нижнего края).
2. Добавить её в `public/assets/manifest.json`:

```json
{
  "figures": {
    "bastion": { "file": "heroes/bastion.png", "facing": "right" },
    "skel": { "file": "mobs/skel.png", "facing": "left" }
  }
}
```

Ключи: герои `bastion`, `ricochet`, `ash`; враги `skel`, `archer`, `slime`, `golem`, `king`. `facing` говорит, куда смотрит фигурка на картинке, чтобы игра разворачивала её к цели. Цветную круглую подставку игра рисует сама: у героев их цвет, у врагов красная.

## Устройство кода

| Файл | Что делает |
| --- | --- |
| `src/data.ts` | герои, мобы, биомы, типы комнат |
| `src/room.ts` | генератор комнаты по сиду |
| `src/game.ts` | правила боя, физика дисков, ходы |
| `src/camera.ts` | изометрия со свободным поворотом и зумом |
| `src/draw/` | отрисовка сцены и фигурок-миниатюр |
| `src/input.ts` | мышь, тач, жесты, клавиатура |
| `src/run.ts`, `src/mapview.ts` | карта забега: 3 этажа по 5 комнат на пути |
| `src/ui.ts` | рамка героя, союзники, верхняя панель |
